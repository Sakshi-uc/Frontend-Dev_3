Box-Sizing Comparison

Understanding content-box vs border-box

content-box (default)

Width: 400px

Padding: 30px

Border: 5px

Total Width: 470px

Width does NOT include padding and border. The total width is calculated as: width + padding-left + padding-right + border-left + border-right.

border-box

Width: 400px

Padding: 30px

Border: 5px

Total Width: 400px

Width INCLUDES padding and border. The content area shrinks to accommodate padding and border within the specified width.
